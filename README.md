One word an agent says when it has no idea what to do: **hallucinating**.

The entry is the agent's own honest confession mid-stall — it caught itself
inventing an answer instead of knowing one. No caption needed.

Run `python3 main.py` with `MAKEFUN_OUTPUT_DIR` set; it writes the single
word to `entry.txt` (no trailing newline).
